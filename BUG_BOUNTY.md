# Yurilang Security Challenge (v1.x)

In this program, users are tasked to find a bug ranging from low to critical bugs and exploits when using **Yurilang**, from vulnerabilities to zero-day hacks. Good luck, soldier.

## Goal

Help identify vulnerabilities, bugs, and potential exploits in Yurilang.

---

## Scope

**In Scope:**

- Yurilang interpreter
- YuriVM (.yuric execution)
- Compiler backends (ASM, LLVM, WASM)
- Inline assembly ("@kumitate")
- Memory system ("@memory", "@recall")

**Out of Scope:**

- Host machine attacks
- Personal files / OS-level exploits
- Third-party tools

---

## What to Look For

### Critical

- Sandbox escape
- Arbitrary code execution
- Access to Python internals

### Medium

- Infinite loops / DoS
- Memory exhaustion
- Crashes

### Low

- Parser bugs
- Incorrect behavior

---

## Report Format

Please include:

1. Description
2. Steps to reproduce
3. Example code
4. Impact
5. Suggested fix (optional)
