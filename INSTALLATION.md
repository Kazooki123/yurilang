# Installation Guide

Here's how you install Yurilang on *all* platforms:

## Windows

The easiest way is to use **Scoop**.

```bash
scoop bucket add yurilang https://codeberg.org/Kazooki123/scoop-yuri.git
scoop install yurilang/yuri
```

## MacOS

> [!WARNING]
> Yurilang hasn't been deployed in Homebrew *yet*

Use **Homebrew**.

```bash
brew tap kazooki123/yuri
brew install yuri
```

## Linux

Run this:

```bash
curl -sSL https://codeberg.org/Kazooki123/yurilang/src/branch/main/install.sh | sh
```

Tadaa! You can now use **Yurilang**!
