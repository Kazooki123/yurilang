# Yuu Package Manager 👩🏼‍❤️‍💋‍👩🏽

Yuu is a **Rust** written package manager for
the **YuriLang** esoteric programming language.

For now it only supports commands such as `yuu init`,
other commands will be implemented in the future.

## Setup

Prerequisites:

- Rust cargo

Build:

```bash
cargo build
```

Test run:

```bash
cargo run init
```

## Bugs & Errors

Expect for bugs and errors, if it does please report it immediately in Issues
