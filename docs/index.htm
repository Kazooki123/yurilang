Welcome to YuriLang

YuriLang v1.8 — Yuring Complete since 2026 ■

A narrative-first esoteric programming language for lesbians, lovers of Yuri media, and anyone who believes code should have a soul.

Philosophy

YuriLang optimizes for emotional resonance. Keywords are drawn from the vocabulary of Yuri stories: @ship, @promise, @bonded, @awaken, and more.

Quick Start

@wlw:
    @confess "Hello, Yuri World! ❤️"
    @promise

Execution modes: Tree-walking interpreter, Bytecode VM (YuriVM), x86-64 ASM compiler.
