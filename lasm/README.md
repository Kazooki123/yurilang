# Lesbian Assembly (LASM)

A custom **Assembly Language** heavily based
on RISC-V/ARM64 instruction sets and ~~keywords~~ registers. Written in **Zig**.

This is used for **Yurilang's** upcoming **Inline Assembly** feature.
