# Girls Love to Compile

**glc** is an ongoing, in development, Rust written compiler that for now is still in it's transpiler stage.

> [!NOTE]
> For now the compiler is recently implemented in **Python**, but once the Rust version is finished, it'll be the primarily compiler for yurilang.

If you want to contribute, you are very much welcome and always appreciated for your work and deserve of credit!! <3
